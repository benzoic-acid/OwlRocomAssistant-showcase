# OwlRocomAssistant

OwlRocomAssistant（ORA）是面向《洛克王国：世界》的本地数据助手。

## 主要功能

- **精灵、图鉴**：查找精灵资料，同步队伍与盒位，筛选、比较和整理个体。
- **家园、背包**：查看种植、繁育、守卫、室内入住、物品、精灵蛋、货币和资产记录。
- **地图**：展示附近精灵、采集资源、地标与捕捉统计，支持目标关注和路线规划。
- **战斗**：查看双方阵容、场上状态、技能、天气、伤害与战报。
- **圣殿**：查看草系徽章试炼的本轮构筑、事件候选与路线，回顾并保存冒险记录。

支持切换已配置账号，查看各自的实时状态与历史记录。

## 界面预览

### 精灵

![ORA 精灵](screenshots/pet-overview.png)

**搜索**：按名称、拼音、首字母或昵称搜索精灵及进化家族。例如，输入“彩蝶鲨”“fengling”“lds”或“啥子鱼”，均可找到风铃鲨家族。也可点击最近捕捉的家族快捷按钮；选中家族后，会提供常用对战性格，方便快速筛选。

**筛选**：按外观、球种、奖牌等条件缩小范围。使用 `Shift + 左键` 排除指定项（NOT）；炫彩颜色、奖牌、蛋组和系别默认匹配任一选中项（OR），使用 `Ctrl + 左键` 可要求同时满足选中项（AND）。

**进化获取果实提醒**：在可进化个体旁显示尚未完成的果实课题进度，提示用户放生前可先进化。

**繁育提醒**：通过“可替代”提示比较繁育候选，决定个体的保留与替换。

**分类整理**：点击盒子的小锁图标，按系别、赛季、体型、声音和性别设置分类规则。设置后小锁变为金色；开启“整理”后，会标记放错位置的精灵并显示建议盒位，协助整理。

# OwlRocomAssistant

OwlRocomAssistant（ORA）是面向《洛克王国：世界》的本地数据助手，用于整理游戏实时状态、本地配置与收藏记录，并在一个统一界面中呈现常用信息。

## 主要功能

- 精灵仓库、队伍与盒位信息
- 背包、货币与资产记录
- 家园、种植与繁育辅助
- 世界地图、附近精灵与采集信息
- 实时战斗状态与战报
- 精灵图鉴与活动日历
- 异色日志、远行商人与拼豆工具

ORA 在本机运行，个人记录保存在用户自己的设备中。
